### 1.3 历史回归（最终）

| 用例 | 历史 ΔNLL | 新系统 ΔNLL | 差异 |
|---|---:|---:|---:|
| no_protection @1e-5 | +0.010470 | +0.010470 | 1.2e-07 |
| ma_uep_without_guard @1e-5 | +0.003489 | +0.003489 | 3.8e-07 |
| ma_uep @1e-5 | +0.000975 | +0.000975 | 3.7e-07 |
| no_protection @1e-4 | +3.360865 | +3.360865 | -4.7e-07 |
| ma_uep_without_guard @1e-4 | +0.032288 | +0.032288 | -3.5e-07 |
| ma_uep @1e-4 | +0.003874 | +0.003874 | 4.8e-07 |
| fixed k=3（无遏制） | +9.491330 | +9.491330 | 3.6e-07 |
| fixed k=3（有遏制） | +0.006037 | +0.006037 | 1.6e-08 |

**8/8 通过。** 差异量级 1e-7，属于 float 累加噪声，说明重构**没有改变任何冻结行为**。

### 1.4 修复的两处保真度问题

| 问题 | 现象 | 修复 |
|---|---|---|
| 分块抽样改变随机流 | BER 回归有 1e-3 级差异 | 改为"整组抽样 + 分块应用"，随机流逐位一致 |
| 固定错误数按等级组抽样 | k=3 场景结果与历史不符（NaN/8.12） | 改为**整张量抽样 + 按比例分摊 150k**，与旧实现一致 |
