# 发布方案修订：从"附带等级图"改为"一条龙生成"

> 起因：等级图 = f(用户提供的模型)，不应该由我们预先算好塞进仓库。

---

## 1. 先回答：一条龙能不能做？

**能，而且成本可控。**

等级图的完整链条是：

```
模型 + WikiText-2
   │  ① 采集各 Linear 输入激活 → F_k = sqrt(mean(x²))
   ▼
F（每通道一个 RMS）
   │  ② 逐权重逐 bit 计算 ΔW = bf16(raw ^ 2^b) − bf16(raw)
   │     S(w,b) = F_k · |ΔW|，Sm​​ax(w) = max_b S(w,b)
   ▼
Sm​​ax（每权重一个分数）
   │  ③ 全局排序 + 分位阈值 → 高/中/低
   ▼
等级图 + 异常遏制阈值 T_k = max|w|
```

三步都不需要额外的外部数据，也不需要 16 GB 的 Bit-level 风险地图——
那是 V0.5 **为了研究**才落盘的中间产物，运行系统并不需要它。

---

## 2. 成本测算（基于已有实测）

| 步骤 | 操作 | 实测/估算耗时 | 内存 |
|---|---|---|---|
| ① F 采集 | 2336 个窗口 × 1 次前向，注册 35 个 hook，累加平方和 | **约 2 分钟**（前向 ~40 ms/窗口） | 每张量 K×8 B（最大 70 KB） |
| ② Smax 扫描 | 234M 权重 × 15 bit，分块向量化 | **约 8 分钟**（V0.5 实测 7.6 分钟） | 分块 1M → 约 30 MB |
| ③ 排序 + 分级 | 直方图求分位阈值 | **约 1 分钟** | O(1) |
| **合计** | 5 个 Block / 35 张量 | **约 11 分钟** | 峰值 < 200 MB |

若扩展到全部 28 个 Block（196 个张量），按比例约 **60 分钟**。

**结论：一次性准备 11 分钟，完全可以接受，仓库因此可以不含任何大数据。**

## 4. 新增命令

```bash
# 一条龙准备：模型 → F → Smax → 等级图 + 阈值
python run.py prepare --model models/Qwen2.5-1.5B-Base

# 之后正常跑实验
python run.py check
python run.py run --mode ma_uep --ber 1e-4 --seed 42
```

`prepare` 的产物：

```text
outputs/prepared/
├── allocation/level_map.npz      # 35 个等级图（压缩）
├── thresholds/tensor_thresholds.json
└── prepare_meta.json             # 模型指纹、数据集、耗时、统计
```

## 5. 新增模块

| 模块 | 职责 |
|---|---|
| `importance/activation.py` | 采集各 Linear 输入通道的 RMS（F） |
| `importance/scan.py` | 逐权重逐 bit 计算 Smax（分块向量化） |
| `importance/prepare.py` | 串起 F → Smax → 阈值 → 等级图 |

现有 `ranker.py` 复用（它已经实现了全局排序与阈值）。
现有 `ImportanceSource` 改为"优先读准备好的产物，缺失时提示运行 prepare"。

## 6. 正确性验证

| 层级 | 方法 | 判据 |
|---|---|---|
| F 一致性 | 新采集的 F vs V0.5 已存的 F | 相对误差 < 1e-5 |
| Smax 一致性 | 新算的 Smax vs 现有 `I_max_log10` | 抽样 1 万权重，相对误差 < 1e-6 |
| 等级图一致性 | prepare 产出的 level_map vs 现有 35 个 | **权重分类一致率 > 99.99%**（阈值边界可能有极少数抖动） |
| 回归 | 用新等级图跑 8 个历史用例 | 与原等级图结果一致（ΔNLL 差异 < 1e-3） |

> 说明：由于浮点累加顺序不同，**不保证逐字节一致**，但分类一致率预期在 99.99% 以上；
> 若出现偏差会如实记录，不改历史数据。

---

## 7. 与"历史可复现"的取舍

- 用 `prepare` + 官方 checkpoint + WikiText-2 test，能够复现论文里的等级分配（差异 < 0.01%）；
- 但若要**逐字节**复现历史等级图，仍可下载我们发布的参考产物（GitHub Release 附件，31.5 MB），
  这是可选项，不进仓库主干。
